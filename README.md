# ApexPlanet Cybersecurity Internship — Task 1

## Foundation and Environment Setup

### Objective
To set up a cybersecurity lab and practise basic Linux commands, network analysis, cryptography, and service scanning.

### Tools Used
- Kali Linux
- VMware / VirtualBox
- Metasploitable2
- Wireshark
- Nmap
- OpenSSL

### Tasks Completed
- Configured an isolated Host-only lab network.
- Tested connectivity between Kali Linux and Metasploitable2 using `ping`.
- Captured ICMP packets using Wireshark.
- Practised basic Linux commands.
- Performed AES-256-CBC encryption and decryption using OpenSSL.
- Scanned the Metasploitable2 lab machine using Nmap service detection.

### Files
- `Task 1.pdf` — Task 1 report with screenshots.
- `Linux_Commands_Cheat_Sheet.txt` — Linux command reference.

### Safety
All scanning was performed against the intended practice lab. Metasploitable2 should remain isolated from public networks.
